# Skip Setup

Marks the Creality first-run/self-test wizard as complete in the printer's
current system configuration. It also sets the screen saver timeout to 120
seconds.

This feature is part of Jacob's recommended setup, but it is not permanent. A
factory wipe, firmware reinstall, or firmware upgrade may recreate the system
configuration and require the feature to be applied again.

Use it only when the printer's hardware checks are already complete and you
intentionally want to bypass the first-run wizard.
