# Obico

Installs the K2-compatible Moonraker-Obico client for remote printer monitoring
and failure detection.

This inherited installer is not exposed by the guided menus because it has not
completed cleanly in current K2 testing and its unguarded clone is not safe to
rerun. Treat it as unsupported experimental material until that installer is
made idempotent and validated end to end.

See [Obico](https://www.obico.io/) for account setup, supported features, and
service documentation.
