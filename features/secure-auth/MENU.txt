Secure Auth disables SSH password login and permits public-key login only.

Read the complete setup guide before installing.

Open in a browser (Ctrl+click or copy the URL):
https://github.com/Rcpilot33/k2-improvements/blob/main/features/secure-auth/SETUP.md

Read directly in the printer SSH terminal:
less /mnt/UDISK/root/k2-improvements/features/secure-auth/SETUP.md

Before installing:
  1. Add a public key to /etc/dropbear/authorized_keys.
  2. Prove key-only login works in a second terminal.
  3. Keep the current session open until that test succeeds.

Incorrect key setup can lock you out of SSH access.
