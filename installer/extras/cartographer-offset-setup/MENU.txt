Select the offset profile matching the physical Cartographer mount:

  - Jamin/default: use the cartographer.cfg baseline.
  - JimmyV legacy (UNTESTED): y=36.
  - JimmyV final without 3DO camera (UNTESTED): y=12.
  - JimmyV final with 3DO camera (UNTESTED): y=17.
    Each JimmyV profile applies its matching mesh limits and stock stepper_y
    values. The final-profile values come from JimmyV's published model page.
  - Custom: enter probe offsets, mesh limits, and the stepper_y source.

Only custom/overrides.cfg is changed. cartographer.cfg and printer.cfg are
preserved. The installer creates a backup and retains the two newest matching
backups.

When no print is active, run FIRMWARE_RESTART and wait for the complete K2
startup sequence. Power-cycle before the next G28 only if that restart reports
an error.
